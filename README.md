О проекте

Bean & Brew — демонстрационный веб-проект кофейни.

Сайт включает:

главную страницу с описанием кофейни;

динамическое меню;

категории товаров;

страницу «О нас»;

адаптивную верстку для мобильных устройств;

форму оформления доставки;

клиентскую валидацию формы;

интеграцию с Google Sheets;

отправку заказов через Google Apps Script;

интеграцию с Telegram-ботом для получения заказов.

Основной функционал
Динамическое меню

Меню загружается из опубликованной Google Таблицы через CSV.

Из таблицы используются:

название товара;

описание;

цена;

категория;

изображение.

JavaScript автоматически формирует категории и карточки товаров.

Форма заказа

Пользователь указывает:

имя;

телефон;

адрес доставки;

состав заказа.

Перед отправкой выполняется клиентская валидация данных.

После успешной отправки пользователь получает подтверждение.

Интеграции

Проект использует Google Apps Script как промежуточный backend для обработки заказов.

Заказ передается из браузера в Apps Script, после чего обрабатывается внешней логикой и передается в Telegram.
